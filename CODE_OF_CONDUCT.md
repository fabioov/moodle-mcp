# Code of Conduct

We want this project to be welcoming to everyone, whatever their background or experience.

## Expected behavior
- Be respectful and constructive. Assume good intent; disagree with ideas, not people.
- Welcome newcomers and answer questions patiently.
- Respect privacy: never post tokens, URLs of private Moodle sites, or real student or staff data
  in issues, pull requests or fixtures.

## Unacceptable behavior
Harassment, discrimination, personal attacks, trolling, publishing others' private information,
or anything else that would be inappropriate in a professional setting.

## Enforcement
Maintainers may edit or remove comments, issues and contributions, and ban people who break these rules.
Report problems privately through a
[GitHub security advisory](https://github.com/fabioov/moodle-mcp/security/advisories/new)
or by contacting the maintainer through their GitHub profile (<https://github.com/fabioov>).
